# 「心绘 ArtMind」视听障碍青少年 AI 艺术疗愈订阅 APP — 产品需求文档（PRD）

> 版本 v1.0 ｜ 文档负责人：产品团队 ｜ 适用对象：视障 / 听障青少年（建议 12–18 岁）、持证艺术疗愈师、绑定家长

---

## 0. 产品定位与价值主张

| 维度 | 内容 |
| --- | --- |
| 一句话定位 | 为视听障碍青少年打造的「无障碍 + AI 多模态」艺术疗愈订阅平台 |
| 目标用户 | ① 视障青少年 ② 听障青少年 ③ 持证艺术疗愈师 ④ 绑定家长 |
| 核心价值 | 用 AI 跨越感官壁垒，让"看不见 / 听不到"的青少年也能创作、欣赏、被疗愈 |
| 商业模式 | Freemium 订阅制（免费版基础能力 + 付费版全量解锁） |
| 合规底线 | 无障碍设计规范 + 未成年人隐私保护 + 内容安全审核 |

设计第一性原则：**任何功能在"完全看不见"或"完全听不到"两种极端情形下都必须独立可用。**

## 2. 四大核心模块需求

### 模块一：AI 多模态艺术创作工坊
内置两类核心 AI 能力：**感官实时转换引擎**与**生成式 AIGC 创作工具**。

**面向视障青少年（无视觉通道）**
- F1.1 语音描述转图像：用户口述场景 → AIGC 生成画作 + 自动生成"音频缩略图"（用声音材质表达画面）。
- F1.2 语音描述转音乐：情绪/场景描述 → 生成旋律片段。
- F1.3 全语音操控绘画：以语音指令操控（"画一片蓝色海洋""把太阳移到左上角"），系统实时朗读画面状态。
- F1.4 艺术品 AI 语音解析：对任意画作输出色彩、构图、情感的语音深描（详见模块三）。

**面向听障青少年（无听觉通道）**
- F1.5 音频/旋律实时视觉可视化：将声音/音乐转为动态频谱、色块、波形画面。
- F1.6 唇语识别辅助创作交互：摄像头读唇 → 转为创作指令文本。
- F1.7 图文一键生成：文字/草图 → AIGC 成品图，全程字幕反馈。

**通用交互约束**
- 每一步操作均有"语音播报 + 字幕 + 触觉反馈"三通道同步反馈。
- 免费版限次（默认每日 3 次 AI 生成），订阅版无限。

### 模块二：个性化 AI 疗愈任务系统
- F2.1 行为采集：自动采集创作行为、情绪反馈（emoji/语音情绪）、障碍类型标签。**情绪数据脱敏后入库（见 §6）。**
- F2.2 分层任务推送：AI 每日生成分层（入门/进阶/挑战）艺术疗愈打卡任务。
- F2.3 治疗师干预：疗愈师可手动调整/重排任务方案，覆盖 AI 推荐。
- F2.4 进度报告：自动生成可量化疗愈进度报告（情绪曲线、完成率、连续打卡），支持读屏朗读与字幕图表。

### 模块三：无障碍艺术欣赏 + AI 冥想引导
- F3.1 AI 智能艺术导览：对画作输出情感 / 色彩 / 构图的深度语音解读 + 同步字幕。
- F3.2 分人群冥想：
  - 视障：纯语音沉浸式冥想（环境声景 + 引导语，无需任何视觉）。
  - 听障：动态视觉旋律冥想（把节律转为呼吸光圈、色彩流动）。
- 免费版提供基础赏析；订阅版解锁全套冥想课程。

### 模块四：未成年人安全线上社区
- F4.1 封闭注册：仅视听障碍青少年、持证疗愈师、绑定家长账号可注册（邀请码 + 资质核验）。
- F4.2 全内容 AI 实时审核：发布即审，敏感内容拦截（见 §7 审核算法）。
- F4.3 私信分级管控：青少年之间私信默认关闭/受限，需家长授权；与疗愈师私信全程留痕可被家长查看。
- F4.4 家长后台：查看社区动态、作品、互动记录、举报与告警。

## 4. 无障碍设计规范（硬性约束）

- A11Y-1 读屏：所有交互元素具备语义化角色与 `aria-*` 标签，关键状态用 `aria-live` 播报。
- A11Y-2 触觉反馈：关键操作触发 `navigator.vibrate` 触觉反馈（移动端）。
- A11Y-3 字幕可视化：所有音频/语音内容提供同步字幕；所有声音事件有视觉指示。
- A11Y-4 对比度与字号：默认满足 WCAG AA（对比度≥4.5:1），支持超大字号/高对比主题切换。
- A11Y-5 操作门槛：支持"语音一键操控"，避免复杂多指手势，所有手势均有按钮替代。
- A11Y-6 焦点管理：全键盘可达，焦点可见，跳转锚点（Skip link）。

## 5. 未成年人安全（硬性约束）

- 封闭社区 + 实名/资质核验 + 邀请制。
- 私信分级（默认关闭青少年互发，疗愈师沟通留痕）。
- 全链路内容审核，敏感词/图像/未成年不宜内容实时拦截。
- 家长监护后台与告警。

## 6. 数据与隐私（硬性约束）

- D-1 加密存储：未成年人 PII 字段（姓名、联系方式、监护关系）字段级加密（AES-GCM）。
- D-2 情绪脱敏：情绪原始数据（语音/表情）不落原文，仅存离散情绪标签 + 不可逆哈希引用。
- D-3 最小采集 + 明示同意 + 监护人知情同意（双同意）。
- D-4 数据可删除（被遗忘权），审计日志留痕。

## 7. 社区审核算法（逻辑见 `server/moderation.js`）
多级流水线：本地敏感词预过滤 → AI 文本/图像分类（涉黄涉暴涉政、欺凌、自伤倾向）→ 风险打分 → 分级动作（放行/打码/拦截/人工复核/危机干预）。对"自伤/自杀倾向"走**危机干预**特殊通道（推送热线 + 通知疗愈师 + 通知家长）。

## 8. 系统架构与交付物索引

```
artmind-app/
├── docs/PRD.md                 # 本文档
├── web/                        # 无障碍前端原型（开箱即用，浏览器直接打开）
│   ├── index.html
│   ├── styles.css
│   ├── app.js                  # SPA 逻辑、语音操控壳、Paywall、a11y 播报
│   └── data.js                 # 演示数据
└── server/                     # 后端参考实现（逻辑/接口/算法）
    ├── schema.sql              # 数据库表结构（含加密/脱敏注释）
    ├── ai-service.js           # AI 多模态接口调用逻辑（感官转换 + AIGC）
    ├── moderation.js           # 社区实时审核算法
    └── subscription.js         # Freemium 订阅 + 支付流程
```

技术栈建议：前端 React Native / Flutter（移动端，强 a11y），本原型用语义化 HTML+原生 JS 演示；后端 Node.js + PostgreSQL；AI 经统一网关路由到各模型供应商。
